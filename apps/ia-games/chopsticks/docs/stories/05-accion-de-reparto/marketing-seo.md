# Story 05 — Tareas de marketing y SEO

## MKT-01: Eventos de analytics del reparto

- Definir eventos:
  - `move_split`: cuando se ejecuta un reparto exitoso. Datos: distribucion anterior, distribucion nueva, si revive mano
  - `split_cancelled`: cuando se abre el panel de reparto pero se cancela
  - `split_panel_opened`: cuando se abre el panel de reparto
- Registrar como stubs para futuro uso

## MKT-02: Copywriting del panel de reparto

- Titulo del panel: "Repartir dedos" o similar
- Texto breve explicativo: "Elige como redistribuir tus dedos" (opcional, solo si cabe sin saturar)
- Boton de cancelar: "Cancelar" o icono X
- Etiqueta de opciones que reviven mano: "Revive mano" o icono
- Tono amigable y comprensible para ninos
